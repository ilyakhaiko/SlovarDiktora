# Словарь диктора

**Словарь ударений русского языка для Android.**

Проверяйте нормативные ударения, узнавайте новые слова и тренируйтесь в удобном темпе. Приложение работает офлайн — без регистрации и обязательного подключения к интернету.

### 📥 Скачать приложение

**[Скачать последнюю версию для Android (APK)](https://github.com/ilyakhaiko/SlovarDiktora/releases/latest)**

На странице релиза откройте раздел **Assets** и выберите файл `SlovarDiktora-*.apk`.

### Возможности

- **Словарь ударений** — поиск слов и просмотр правильных ударений.
- **Слово дня** — новые слова, тематические подборки и виджет для главного экрана.
- **Тренировка** — практика постановки ударений.
- **Резервное копирование** — экспорт и восстановление пользовательских данных.
- **Офлайн-работа** — основные функции доступны без интернета.

### Установка и обновление

1. Скачайте APK из [последнего релиза](https://github.com/ilyakhaiko/SlovarDiktora/releases/latest).
2. Откройте файл на Android-устройстве. Если Android запросит разрешение на установку из этого источника, предоставьте его для используемого приложения (например, браузера или файлового менеджера).
3. Для обновления скачайте APK новой версии и установите его поверх предыдущей.

Предыдущую версию удалять не нужно. Для обновления поверх существующей установки используется тот же идентификатор приложения и ключ подписи.
